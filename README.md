# verbAfrica

A curated booking directory for South African creatives: musicians, DJs, MCs, photographers, producers, venues and more.

**Live site:** https://www.verbafrica.co.za

## What's here

| File | What it is |
|---|---|
| `index.html` | The whole site: a single static page |
| `data/creatives.json` | The creative profiles the site displays |
| `images/` | Profile photos |
| `CNAME` | Custom domain for GitHub Pages |

The site is served by GitHub Pages from the `main` branch. Enquiries submitted on the site go privately to the verbAfrica team; nothing a visitor submits is published.

## Contact

Bookings, partnerships or questions: alexander@verbafrica.co.za, or use the forms on the site.

See the privacy notice on the site for how submitted information is handled.
